# Employee Management System

A backend-focused Employee Management System developed using **Core Java, MySQL, and JDBC**.
The project is being developed step-by-step with the goal of evolving into a complete full-stack application.

## 🚀 Project Status

**Currently in development — Stage 2**

### Stage 1 — Core Java ✅

* Implemented object-oriented programming concepts
* Created Employee-related classes and application structure
* Worked with `ArrayList` and `HashMap`
* Implemented loops and conditional statements
* Practiced string operations and basic algorithms
* Implemented exception handling using `try-catch`, `throw`, and `throws`
* Built the initial employee management logic using Core Java

### Stage 2 — MySQL + JDBC 🚧

* Created the `employee_db` MySQL database
* Designed the Employee table
* Configured Java–MySQL connectivity using JDBC
* Implemented the database connection layer
* Started integrating the Java application with MySQL
* Currently developing JDBC-based CRUD operations
